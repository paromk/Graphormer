Graph Structure
Node structure
  • ~60 nodes representing mesh nodes relevant to the N. Pacific + coastal nodes + climate modes tokens
  • Each mesh/coastal node has features — regionally and 7-day averaged: Z500, IVT_x, IVT_y, + tendencies, etc.
Global state nodes
RMM1RMM2 QBOENSO AOPDO IODPNA NPODOY Lag
Edges
  • Fully connected
  • Attention patterns inform strength of node–node interaction given different contexts
Example: in a high-ENSO / active-MJO state, attention weights from tropical and ENSO tokens to coastal nodes are expected to strengthen, capturing teleconnection pathways.

Member layout (same in both experiments)

  • 10 single members: LE2-1001 to LE2-1181 (cmip6), LE2-1011 to LE2-1191 (smbb)
  • 4 groups of 10 members: LE2-1231, 1251, 1281, 1301
  • Folder pattern: b.e21.<exp>.f09_g17.LE2-<id>.<nnn>

Variables per member (one file per decade)

  • FLUT (OLR proxy), PS, TS, Z500
  • U, V, Q on model levels; U_plev, V_plev, Q_plev on pressure levels
  • U200, V200, U850
  • No IVT stored; compute from U, V, Q
cam.h1 (likely daily) and cam.h6 (likely sub-daily) frequencies are not yet verified.

Helper folders

  • Codes_for_RMM/: MJO RMM EOF and anomaly scripts
  • YYYYMMDD_for_RMM_indices/: calendar lookup files
  • RMM_pattern_correlations/: FLUT pattern-correlation tables
  • MJO FLUT composite files (summer and winter, 100-member mean)
